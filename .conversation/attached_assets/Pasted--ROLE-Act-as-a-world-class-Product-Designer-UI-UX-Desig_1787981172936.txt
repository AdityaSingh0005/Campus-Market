# ROLE

Act as a world-class Product Designer, UI/UX Designer, Frontend Engineer and Startup Product Architect.

You are designing and building a real-world **Campus Buy & Sell Marketplace** for students of **Pondicherry University, India**.

This is NOT an OLX clone, NOT a social media app, and NOT a complicated e-commerce platform.

The core philosophy is:

> **"Buying and selling on campus should be as easy as sending a WhatsApp message."**

The product must feel extremely simple, fast, trustworthy, modern and premium.

---

# PRODUCT VISION

Students at Pondicherry University currently use WhatsApp Buy & Sell groups to sell:

* Cycles
* Bikes
* Laptops
* Phones
* Electronics
* Books
* Clothes
* Hostel items
* Furniture
* Sports equipment
* Accessories
* Other useful student items

The problem with WhatsApp groups is that:

* Groups have member limits.
* Old students don't leave.
* New students cannot always join.
* Old listings become difficult to find.
* There is no proper search.
* There are no categories.
* Sold items remain mixed with active items.
* Important listings disappear in the chat.
* Finding a specific item is frustrating.

Build a dedicated campus marketplace that solves these problems while keeping the simplicity of WhatsApp.

---

# TARGET USERS

Primary users:

* Pondicherry University students
* New students
* Existing students
* Students living in hostels
* Students buying/selling used items before leaving campus

The target user should NOT need technical knowledge.

A student should understand the website immediately without instructions.

---

# CORE PRODUCT PRINCIPLE

Follow this rule throughout the entire product:

> **If a feature makes the product more complicated without solving a major user problem, DO NOT ADD IT.**

Prioritize:

1. Simplicity
2. Speed
3. Trust
4. Discoverability
5. Mobile usability
6. Premium visual quality

Do NOT add unnecessary features just to make the product look bigger.

---

# MVP FEATURES

Build only these core features initially:

## 1. Authentication

Allow users to:

* Continue with Google
* Create an account
* Log out

Do not use complicated registration forms.

The user's phone number should NOT be publicly displayed.

# 2. CAMPUS IDENTITY

Every verified user should have:

* Pondicherry Technological University
* PIMS

---

# 6. WHATSAPP-FIRST COMMUNICATION

DO NOT build an internal chat system.

The platform should use WhatsApp for communication.

When the user clicks:

**Contact Seller on WhatsApp**

open WhatsApp with a pre-filled message such as:

"Hi, I saw your Firefox Cycle listing on Campus Market. Is it still available?"

The seller's phone number should NOT appear as visible plain text on the listing.

This keeps the experience familiar and reduces unnecessary exposure of personal contact information.

---

The selling process must be extremely fast.

Target:

> A student should be able to publish an item in less than 60 seconds.

Create a prominent:

**+ Sell Item**

button.

The form should contain only necessary fields:

### Photos

Allow multiple product images.

### Item title

Example:

Firefox Cycle

### Price

₹

### Category

Select category.

### Condition

* Like New
* Good
* Fair

### Description

Optional but useful.

### Location

Example:

Boys Hostel

### WhatsApp number

Private.

Never display this number publicly.

### Publish Listing

Large primary button:

**Post Item**

Avoid unnecessary fields.

**My Listings**

This is important.

The platform is public-facing, therefore:

### NEVER publicly display:

* Seller phone number
* Private email
* Authentication information

Instead show:

**Contact on WhatsApp**

* Report listing

* Input validation

* Image upload validation
* File size restrictions
* Basic spam prevention

Design the system so personal information is minimized.
